# Payroll API

NestJS, Prisma, SQLite, and JWT backend. See the [root README](../README.md) for full setup, credentials, assumptions, and deployment.

After dependency and environment setup:

```sh
npm run prisma:generate
npm run db:deploy
npm run build
npm start
```

Swagger: http://localhost:3000/docs. Unit tests: `npm test -- --runInBand`.
